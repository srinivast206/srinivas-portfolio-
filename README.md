# Srinivas T. — Instructional Designer & E-Learning Developer

A responsive personal portfolio website for Srinivas T.

## Files
- `index.html` — website homepage
- `profile.png` — profile image used in the About section

## Publish with GitHub Pages
1. Upload `index.html`, `profile.png`, and `README.md` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Wait for GitHub Pages to publish the site.

The website contains no Featured Projects section and does not display office project names or descriptions. It includes expertise, toolkit, knowledge and skills, services (including learner assessments), and delivery process sections.

All decorative website illustrations are original inline SVG artwork. The profile photo is supplied by the site owner.
